# 相関図エディター

ブラウザー上で人物カード、グループ、メモ、矢印を配置して、現場の関係図を作成するシンプルなエディターです。インストール不要で、GitHub Pagesから利用できます。

## 公開ページ

[相関図エディターを開く](https://temochiz-lab.github.io/20261118soukanzu/)

## サンプルを開く

- [相関図サンプル](https://temochiz-lab.github.io/20261118soukanzu/?sample=sample)
- [徳川将軍家系図](https://temochiz-lab.github.io/20261118soukanzu/?sample=tokugawa)

リンクを開くと、既存のタブを残してサンプルを新しいタブに読み込みます。URLの `sample` 引数でサンプルを指定しています。

## 起動方法

- 公開ページを開くか、`index.html`をブラウザーで開きます。
- PNGアイコンを使う場合は、`personcard/`フォルダーを`index.html`と同じ階層に置いてください。`file://`で開く場合、ブラウザーによってはローカル画像の読み込みが制限されるため、GitHub PagesまたはローカルWebサーバーでの利用をおすすめします。

## 主な機能

- 人物カード、色付きグループ、四角・丸メモの追加と編集
- 人物カードとグループを結ぶ矢印の作成、色・ラベル・方向・線種・角の設定
- 矢印の折れ点とラベル位置の調整、選択した矢印の「矢印」→「整列」による直角化・重なり回避
- グリッド表示切り替え、グリッドに沿った移動とサイズ変更
- 複数選択、コピー・ペースト、削除、Undo、表示倍率変更、キャンバス移動
- PNG画像のクリップボードコピーとファイル保存、編集用ファイルの読み込み・保存
- 複数の相関図タブの追加・名前変更・切り替えと、全タブのブラウザー内自動保存

## 操作の概要

- 2行目のツールバーから人物カード、メモ、グループ、矢印を追加します。
- 初期状態は「手のひら」です。オブジェクトの選択や編集には、キャンバス左上の「選択」ツールを使います。
- オブジェクトをクリックして選択し、ドラッグで移動します。角のハンドルをドラッグするとサイズを変更できます。
- オブジェクトをダブルクリックすると、カードやメモのテキストをその場で編集できます。
- 矢印を追加したら、始点のオブジェクト、続けて終点のオブジェクトをクリックします。グループも接続先にできます。
- `Ctrl`または`Shift`を押しながらクリックすると複数選択できます。選択オブジェクトのドラッグでまとめて移動できます。
- 空白をドラッグして範囲選択するには「選択」ツールを使います。「手のひら」ツールでは空白ドラッグでキャンバスを移動します。
- `Delete`で選択項目を削除、`Ctrl+Z`でUndo、`Ctrl+C` / `Ctrl+V`でオブジェクトをコピー・ペーストします。
- オブジェクトを右クリックすると、プロパティや前面・背面、コピーなどのメニューを開けます。空白を右クリックするとペーストできます。コピーしたオブジェクトは別のタブにも貼り付けられます。別タブに矢印を貼るときは、その両端のオブジェクトも一緒に選んでコピーしてください。
- 「矢印」→「整列」は選択中の矢印を対象にします。通常の移動やコピーでは矢印の経路を自動再計算しません。

## 保存データについて

相関図のタブは、上部の「＋ タブ追加」で追加できます。タブを切り替えてそれぞれの図を編集し、「名前変更」またはタブ名のダブルクリックで名前を変えられます。不要なタブは「削除」で削除できます。Undoの履歴はタブごとです。

全タブの編集内容は、ブラウザーの`localStorage`に自動保存されます。保存データはブラウザーと端末ごとに保持されます。「ファイルに保存」は全タブをまとめて保存し、「ファイルを開く」は確認後にファイル内の全タブを読み込みます。編集用ファイルにはJSON形式（.json）を使用します。タイトル横の「ファイル名」は編集用ファイルとPNG画像の保存名の先頭に付き、初期値は`untitled`です。従来の単一の相関図ファイルも読み込めます。読み込み時は現在のタブ全体が読み込んだ内容に置き換わるため、必要に応じて事前にファイルに保存してください。

「共有URL」は現在のタブを圧縮したURLをコピーします。受け取った人がURLを開くと、既存の図を残して新しいタブに図を取り込み、そのまま編集できます。共有されるのは作成時点のコピーで、変更は自動同期されません。URLを知る人は図の内容を読めるため、共有先に注意してください。図が大きくURLが8,000文字を超える場合は、「ファイルに保存」を利用してください。

「イメージをコピー」は現在のタブの選択中の要素（選択がない場合は現在のタブの図全体）をPNGとしてクリップボードへコピーします。「イメージを保存」は同じ内容をPNGファイルに保存します。

## 個人情報について

- 相関図の編集内容は、利用中のブラウザー内にのみ自動保存され、サーバーには保存されません。ファイルや画像として保存した場合は、保存先のファイルにも内容が含まれます。
- 共有URLには相関図のデータが含まれます。URLを受け取った人は内容を閲覧・編集できるため、個人情報を含む図の共有先や取り扱いに注意してください。

## アイコン

人物アイコンは`personcard/`フォルダーの透過PNGです。用意されているアイコンをそのまま使うか、プロパティの「PNGアイコンを読み込む」から画像を設定できます。人物カードに使うアイコンファイルは、このフォルダーに追加してください。
