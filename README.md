# 相関図エディター

ブラウザー上で人物カード、グループ、メモ、矢印を配置して、現場の関係図を作成するシンプルなエディターです。インストール不要で、GitHub Pagesから利用できます。

## 公開ページ

[相関図エディターを開く](https://temochiz-lab.github.io/20261118soukanzu/)

## 起動方法

- 公開ページを開くか、`index.html`をブラウザーで開きます。
- PNGアイコンを使う場合は、`personcard/`フォルダーを`index.html`と同じ階層に置いてください。`file://`で開く場合、ブラウザーによってはローカル画像の読み込みが制限されるため、GitHub PagesまたはローカルWebサーバーでの利用をおすすめします。

## 主な機能

- 人物カード、色付きグループ、四角・丸メモの追加と編集
- 人物カードとグループを結ぶ矢印の作成、色・ラベル・方向・線種・角の設定
- 矢印の折れ点とラベル位置の調整、選択した矢印の「矢印を清書」による直角化・重なり回避
- グリッド表示切り替え、グリッドに沿った移動とサイズ変更
- 複数選択、コピー・ペースト、削除、Undo、表示倍率変更、キャンバス移動
- PNG画像のクリップボードコピーとファイル保存、JSONの読み込み・書き出し
- 変更内容のブラウザー内自動保存

## 操作の概要

- 2行目のツールバーから人物カード、メモ、グループ、矢印を追加します。
- 初期状態は「手のひら」です。オブジェクトの選択や編集には、キャンバス左上の「選択」ツールを使います。
- オブジェクトをクリックして選択し、ドラッグで移動します。角のハンドルをドラッグするとサイズを変更できます。
- オブジェクトをダブルクリックすると、カードやメモのテキストをその場で編集できます。
- 矢印を追加したら、始点のオブジェクト、続けて終点のオブジェクトをクリックします。グループも接続先にできます。
- `Ctrl`または`Shift`を押しながらクリックすると複数選択できます。選択オブジェクトのドラッグでまとめて移動できます。
- 空白をドラッグして範囲選択するには「選択」ツールを使います。「手のひら」ツールでは空白ドラッグでキャンバスを移動します。
- `Delete`で選択項目を削除、`Ctrl+Z`でUndo、`Ctrl+C` / `Ctrl+V`でオブジェクトをコピー・ペーストします。
- オブジェクトを右クリックすると、プロパティや前面・背面、コピーなどのメニューを開けます。空白をクリックするとプロパティを閉じます。
- 「矢印を清書」は選択中の矢印を対象にします。通常の移動やコピーでは矢印の経路を自動再計算しません。

## 保存データについて

図の編集内容は、ブラウザーの`localStorage`に自動保存されます。保存データはブラウザーと端末ごとに保持されます。別の端末へ移す場合やバックアップする場合は、「JSON書き出し」を利用してください。JSONファイルは「JSON読み込み」から戻せます。

「イメージをコピー」は選択中の要素（選択がない場合は図全体）をPNGとしてクリップボードへコピーします。「イメージを保存」は同じ内容をPNGファイルに保存します。

## アイコン

人物アイコンは`personcard/`フォルダーの透過PNGです。用意されているアイコンをそのまま使うか、プロパティの「PNGアイコンを読み込む」から画像を設定できます。人物カードに使うアイコンファイルは、このフォルダーに追加してください。
